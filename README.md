# CampusOS AI

CampusOS AI is an autonomous academic assistant designed to organize information scattered across platforms such as Gmail, Google Classroom, WhatsApp, ERP and Calendar.

## Problem

Students receive academic information from multiple platforms. Deadlines, announcements, study materials and other important updates are difficult to track in one place.

## Solution

CampusOS AI brings this information together and uses an AI agent to understand, remember, prioritize and assist the student.

## Core Features

- Centralized academic dashboard
- AI assistant
- Deadline and task management
- Personalized memory
- Smart calendar
- PDF summarization
- Flashcard generation
- Proactive reminders

## Technology

Frontend: React, Tailwind CSS

Backend: FastAPI

AI: Gemini

Database: MongoDB

OCR: Tesseract

NLP: spaCy
